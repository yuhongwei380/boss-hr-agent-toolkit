    卡片粗筛

    只看推荐列表卡片上已经写出来的字。没写到的信息不会因此刷掉。

    院校门槛

    选一档作为最低要求，这一档及以上都过。点「不限」则不卡学校。技术岗常选 211 / 一本公办，销售岗常选二本或不限，实习看学校可以选更高。

    希望看到的技能或方向

    卡片上出现其中任意一个更好，例如 Java、MySQL。卡片太短没写到，也不会因此刷掉。每个词回车添加。

    不想要的人（出现就刷掉）

    卡片上出现这些字就不要。技术岗不想要非全日制，填 非全日制，回车添加。还可按卡片原文加：函授、自考、销售。
